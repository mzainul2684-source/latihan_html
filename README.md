## Deskripsi

Pada modul ini dilakukan latihan dasar pembuatan halaman web menggunakan **HTML**. Praktikum mencakup pembuatan struktur folder dan file HTML, penggunaan struktur dasar HTML, pengisian konten halaman, pembuatan hyperlink antarhalaman, serta pemeriksaan hasil dan navigasi melalui browser.

## Struktur Folder

Struktur folder yang digunakan dalam praktikum adalah:

```text
webpro-NIM/
├── index.html
├── tentang.html
└── kegiatan.html
```

Repository ini menggunakan tiga halaman utama:

* `index.html` sebagai halaman **Profil Praktikan**
* `tentang.html` sebagai halaman **Tentang Saya**
* `kegiatan.html` sebagai halaman **Kegiatan Saya**

## Materi yang Dikerjakan

### 1. Membuat Folder dan File

Membuat folder proyek serta tiga file HTML sesuai struktur yang telah ditentukan.

### 2. Menulis Struktur HTML

Setiap halaman menggunakan struktur dasar HTML, meliputi:

* `<!DOCTYPE html>`
* `<html>`
* `<head>`
* `<meta charset="UTF-8">`
* `<title>`
* `<body>`
* Heading dan paragraf

Judul tab disesuaikan dengan masing-masing halaman.

### 3. Mengisi Halaman Profil dan Tentang

Pada halaman `index.html`, ditampilkan:

* Nama lengkap
* NIM
* Kelas
* Perkenalan singkat
* Target Belajar
* Dua paragraf mengenai target belajar

Pada halaman `tentang.html`, ditampilkan judul **Tentang Saya** serta alasan mempelajari pembuatan website.

### 4. Membuat dan Memperbaiki Tautan

Menambahkan hyperlink untuk menghubungkan halaman satu dengan halaman lainnya.

Navigasi yang dibuat:

```text
index.html
   ├── Tentang Saya → tentang.html
   └── Kegiatan Saya → kegiatan.html

tentang.html
   └── Kembali ke Profil → index.html

kegiatan.html
   └── Kembali ke Profil → index.html
```

Pada praktikum juga dilakukan perbaikan `href` dari `about.html` menjadi `tentang.html` agar tautan mengarah ke nama file yang benar.

### 5. Mengisi Halaman Kegiatan

Pada `kegiatan.html` dibuat:

* Judul halaman **Kegiatan Saya**
* Dua bagian kegiatan menggunakan `<h2>`
* Satu paragraf deskripsi untuk setiap kegiatan
* Tautan **Kembali ke Profil**

Halaman `index.html` juga dilengkapi tautan menuju **Kegiatan Saya**.

### 6. Memeriksa Hasil

Seluruh file HTML disimpan kemudian dibuka melalui browser untuk memastikan isi halaman tampil dengan benar dan seluruh tautan dapat digunakan dengan baik.
